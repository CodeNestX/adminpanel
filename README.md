# adminpanel

پنل مدیریت پروژه adminpanel_car

## شروع کار

ابتدا وابستگی‌های پروژه رو نصب کن:

```bash
npm install
```

سپس سرور توسعه رو اجرا کن:

```bash
npm run dev
```

حالا مرورگر رو باز کن و به آدرس زیر برو:

http://localhost:3000

## فناوری‌ها

- Next.js
- React
- TypeScript
- Tailwind CSS

## ساخت نسخه نهایی

برای ساخت نسخه Production:

```bash
npm run build
```

برای اجرای نسخه Production، ابتدا Build رو بساز و سپس اجرا کن:

```bash
npm run start
```
